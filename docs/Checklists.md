# PBOS Checklists

## Counsel (both sides)
- [ ] Confirm “The Science” definition and pre-/post-training boundary
- [ ] Confirm ownership split and licenses (commercial rights to Company; publication rights to University)
- [ ] Add confidentiality and publication review windows (30 days + optional 90-day patent hold)
- [ ] Include operational safeguards + audit rights
- [ ] Set dispute resolution contact path

## Engineering / IT (Company)
- [ ] Provision Company-controlled environment + SSO for University users
- [ ] Block exports of Trained Weights / raw data
- [ ] Enable artifact manifest + hash tooling
- [ ] Log access + changes; retain for audits

## Research (University)
- [ ] Keep code/repos structured to separate Science artifacts from Business artifacts
- [ ] Document experiments; publish only Science-side outputs
- [ ] Observe review windows where drafts may implicate confidential info
